# 💈 Sistema de Gerenciamento para Barbearia

> Aplicação web desenvolvida em Java com Spring Boot para o gerenciamento completo de uma barbearia, facilitando o agendamento de serviços, controle de clientes e organização da agenda.

---

## 📌 Sobre o Projeto

O projeto foi construído com foco em eficiência e organização de uma barbearia. O sistema permite o cadastro e controle de horários, serviços prestados, profissionais e clientes, oferecendo uma interface dinâmica e integrada ao backend.
A ideia surgiu quando meu amigo (barbeiro) reclamou do seu sistema atual e eu estava fazendo outro projeto parecido na faculdade, fiz baseado na minha Locadora Web.

### 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java (JDK 25)
* **Framework Backend:** Spring Boot (Spring Web, Spring Data JPA)
* **Template Engine (Frontend):** Thymeleaf
* **Banco de Dados:** MySQL
* **Gerenciador de Dependências:** Maven
* **Ferramenta de Desenvolvimento:** IntelliJ IDEA

---

## 💻 Funcionalidades Principais

- [x] **Gestão de Agendamentos:** Marcação, alteração e cancelamento de horários para os clientes.
- [x] **Cadastro de Serviços:** Gerenciamento de cortes, barbas e combos, com definição de preços e durações.
- [x] **Gestão de Clientes e Barbeiros:** Listagem, cadastro e histórico de atendimentos.
- [x] **Painel de Controle (Dashboard):** Visualização rápida dos compromissos do dia.
